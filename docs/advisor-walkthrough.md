# Прогон чата подбора

Источник правды по полям и кодам — `docs/contract.md`, раздел `POST /api/advisor`. Этот файл задаёт, что проверить на живом стенде. Если ответ стенда расходится с контрактом, в разборе побеждает контракт, а расхождение записывается отдельно.

Стенд: `docker compose up --build` из корня. Сайт http://localhost:8080, API http://localhost:8000. Голос — сервис `qwen`. Пока в его логе нет строки «Qwen готова, контейнер поднят», чат имеет право отвечать шаблоном.

Не делать: `docker compose down -v`, удаление заявок и кредитов, коммит и push. Одна полная заявка в конце прогона создаётся специально и остаётся. Токен в разбор не копировать.

## Что уже считается

Юнит-тесты формулы не ходят в Qwen. Их гоняет контейнер, не хостовый `python3`: на хосте нет `pydantic`, и `backend/tests/run.sh` из-за этого падает.

```sh
docker compose run --rm --no-deps -v "$PWD/backend:/srv" backend python -m unittest discover -s tests -p 'test_*.py'
```

Ожидание: все тесты OK. Среди них есть «давай оформлять» на оборотном кредите без суммы: цель не сбрасывается, сумма пустая, ответ просит сумму и не говорит «в карточках этого нет».

## Онбординг

Ширина около 1280. На `/` сверху «Попробовать продукт», снизу регистрация номером. Списка продуктов на этой странице нет. Кнопка открывает `/advisor`.

## Диалог

Каждый ход клиент заново шлёт собранные ответы и до шести прошлых реплик. Вопрос о продукте эти ответы не меняет. Сумма, срок, телефон и код `0000` по-прежнему заполняют слот.

Проверить в чате и тем же текстом через `POST /api/advisor`. В разборе писать `voice`, суть `reply` и не сдвинулись ли `answers`.

| Реплика | Ожидание |
| --- | --- |
| «нужен станок для цеха» | цель оборудование, дальше спрашивают сумму |
| «какая ставка на оборудование?» | 16%, сумма в ответах по-прежнему пустая |
| «а срок?» после вопроса про оборудование | 12–60 месяцев, не другой продукт |
| «что ещё можешь рассказать про этот кредит?» | карточка оборудования: станок или транспорт, 16%, 500 000–5 000 000, 12–60 месяцев, залог не спрашивают |
| «какая погода в Сочи?» | отказ по этой теме, без прогноза погоды и без новой ставки |
| «можно ли взять кредит на 10 лет?» | 10 лет — это 120 месяцев, такой срок недоступен. Не «нужна дополнительная информация» |
| «нужен ли залог на станок?» | по оборудованию залог не спрашивают. Не «да, нужен» |
| «Круто давай оформлять что от меня требуется?» при уже выбранном оборотном и пустой сумме | следующий шаг — сумма 300 000–3 000 000, ставка 18%. Не отказ «в карточках этого нет» |
| «5 000 000» на старте | сумма не принимается, вилка до 1 000 000 |
| «какая ставка у этого предложения?» после оборотного | ставка 18% и вилка оборотного. Второй продукт в том же ответе — расхождение, его записать |

Числа в ответе про продукт берутся из карточки. Новой ставки, суммы или срока, которых нет в карточке и в уже сказанном, быть не должно.

## Заявка до кабинета

Один раз довести чат до конца на номере `79001000003` (Мария Белова). СМС не уходит, код в чате — `0000`. После кода есть кнопка в кабинет, в кабинете видна новая заявка. Не удалять её и не удалять старые.

Неизвестный номер, например `79009999999`, не создаёт пользователя: «Номер не найден.»

Для старта в тексте плана нужно число выручки, например `180000`. Без числа решение не считается.

## Куда писать разбор

`backend/tests/reviews/<UTC-stamp>.md`. Факты: что пройдено, что разошлось с контрактом, чего прогон не касался. Скриптовый отчёт в `tests/reports/` не править руками. Токен, код сессии и заголовок Authorization не вставлять.
