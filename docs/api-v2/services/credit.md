# credit

Сервис `backend`. База только своя, хост Compose — `credit-db`.

Кабинет, сессия, заявки и кредиты описаны в `docs/contract.md`. Клиент вызывает те же пути через `@alfa-hack/core-api`.

Вход только по номерам из `GET /api/demo-profiles`. Эти пользователи и их кредиты создаются при старте сервиса. Неизвестный номер не регистрируется.

`POST /api/advisor` подбирает продукт до входа. Формула решает вопрос, вилку и когда спросить номер. Голос — базовая Qwen2.5-1.5B-Instruct без адаптера, если поднят `ML/scripts/paraphrase_qwen.py` и контейнер достучался до `ADVISOR_LLM_URL` (`host.docker.internal` через `host-gateway`). Иначе фразу собирает шаблон по триггерным словам. Свободный вопрос ищется по `ML/knowledge` и пересказывается только из найденной карточки. Ссылка на уже сказанное («этот кредит», «что ещё») ищется по последним репликам человека. Модель видит до шести реплик. Без карточки модель отказывает своими словами и не выдумывает ответ. Без модели чат просит переформулировать. Код `0000` записывает заявку на демо-номер и открывает сессию. Подробности в `docs/contract.md`.

## `GET /health`

Токен не нужен. Это readiness, не часть кабинетного JSON.

`200`

```json
{"status": "ok"}
```

`503` — Postgres не ответил на `SELECT 1`.

```json
{"status": "error", "reason": "db"}
```

Путь смотрят у процесса сервиса. На стенде это порт 8000. Origin кабинета на `/health` отдаёт HTML страницы входа со статусом 200. Это не готовность и не кабинетный JSON.

## Кэш
