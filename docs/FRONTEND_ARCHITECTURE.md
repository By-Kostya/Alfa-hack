# Фронтенд

```text
backend /api
    ▲
@alfa-hack/core-api      HTTP, без React
@alfa-hack/core-auth     номер телефона
@alfa-hack/core-credit   подписи, проверка анкеты, суммы
    ▲
frontend/src             экраны
```

Новый расчёт или правило статуса живёт в `core-*`. Экран только вызывает эти функции и рисует разметку. Подбор продукта до входа не считает вилку сам: экран шлёт реплику в `POST /api/advisor` и рисует ответ. Черновик диалога лежит в `sessionStorage`, пока чат не запишет заявку на номер.
