# Альфа-Бизнес — кредитный кабинет

Нужны Docker и Docker Compose. Отдельный `.env` не обязателен.

```sh
docker compose up --build
```

Откройте http://localhost:8080

Регистрации нет. На экране входа три профиля, по ним можно войти:

| Номер | Кто |
| --- | --- |
| 79001000001 | Анна Соколова, ООО «Северная линия» |
| 79001000002 | Илья Морозов, ИП Морозов И. С. |
| 79001000003 | Мария Белова, ООО «Контур Снаб» |

В кабинете уже есть заявки и кредиты. Новую заявку можно отправить по любому продукту: оборотный, старт, оборудование, контракт, овердрафт, рефинансирование. У каждого продукта свои ставка, сумма и срок. Дольше 60 месяцев взять нельзя, у овердрафта и контракта срок короче. Для старта в тексте плана укажите выручку, например `180000`.
