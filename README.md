# Альфа-Бизнес — кредитный кабинет

Нужны Docker и Docker Compose. Отдельный `.env` не обязателен.

```sh
docker compose up --build
```

Откройте http://localhost:8080

Регистрации нет. На экране входа три профиля, по ним можно войти:

| Номер | Кто |
| --- | --- |
| 79001000001 | Анна Соколова, ООО «Северная линия» |
| 79001000002 | Илья Морозов, ИП Морозов И. С. |
| 79001000003 | Мария Белова, ООО «Контур Снаб» |

Стартовый экран — онбординг: сверху «Попробовать продукт», снизу регистрация номером. Чат спрашивает задачу, сумму, срок и выручку, потом номер из демо-профилей и код `0000`. СМС не уходит, код написан в чате. Заявка сохраняется на этот номер. Числа считает формула. Фразу может сказать базовая Qwen2.5 на 1,5 млрд параметров, без дообучения. Если модель не поднята, те же реплики говорят заготовленные фразы:

```sh
python3 ML/scripts/paraphrase_qwen.py
```

Пока этот процесс не запущен, чат отвечает шаблонами. Вопрос о продукте ищется по карточкам в `ML/knowledge`. «Этот кредит» и «что ещё» ищутся по последним репликам человека. Если карточки нет, модель отказывает своими словами по последним репликам и не отвечает по своей памяти. Если не поднялась модель или поиск, он просит переформулировать вопрос. В кабинете уже есть заявки и кредиты. Новую заявку можно отправить по любому продукту: оборотный, старт, оборудование, контракт, овердрафт, рефинансирование. У каждого продукта свои ставка, сумма и срок. Дольше 60 месяцев взять нельзя, у овердрафта и контракта срок короче. Для старта в тексте плана укажите выручку, например `180000`.
